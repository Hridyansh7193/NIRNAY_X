# How to Compile nirnay_x_research_paper.tex

This paper is prepared in the official IEEE 2-Column Conference / Transactions research paper format, matching the reference paper style (AKGEC / AKTU standard).

------------------------------------------------------------------------
Option 1: Overleaf (Recommended - 1-Click Zero Setup)
------------------------------------------------------------------------
1. Go to https://www.overleaf.com and log in (free account).
2. Click "New Project" -> "Upload Project".
3. Upload `nirnay_x_research_paper.tex` (and optionally `IEEEtran.cls` if requested, though Overleaf has IEEEtran built-in).
4. Click "Recompile".
5. Click "Download PDF".

------------------------------------------------------------------------
Option 2: Local Compilation with MiKTeX or TeX Live (Windows / Linux / macOS)
------------------------------------------------------------------------
1. Open PowerShell / Terminal.
2. Navigate to this folder:
   cd "C:\Users\rajat\Desktop\FINAL YEAR RESEARCH\FINAL"
3. Run pdflatex twice (to resolve references, citations, and labels):
   pdflatex nirnay_x_research_paper.tex
   pdflatex nirnay_x_research_paper.tex
4. Output: `nirnay_x_research_paper.pdf` will be generated in the same directory.
